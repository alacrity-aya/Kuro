# Kuro Frontend Test Progress

## 项目概述

本项目是 Kuro 分布式网络模拟平台的前端测试跟踪文件。

### 测试目标
- 验证所有已实现功能的正确性
- 确保代码质量和用户体验
- 捕获回归问题

### 技术栈
- React 19 + TypeScript
- Vite 构建工具
- Vitest 单元测试
- React Flow 拓扑可视化
- Monaco Editor YAML 编辑
- MCP 浏览器自动化测试

## 测试命令

```bash
# 运行完整测试循环
./scripts/run-test-agent-loop.sh 10

# 从上次中断处继续
./scripts/run-test-agent-loop.sh 10 --resume

# 只运行代码测试（跳过浏览器）
./scripts/run-test-agent-loop.sh 10 --no-browser

# 测试单个功能
./scripts/run-test-agent-loop.sh --feature FEAT-015
```
